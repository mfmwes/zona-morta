# Atalhos da cena visual

Clique na cena ou use Tab para focar o editor. Os atalhos funcionam somente dentro do editor do mestre e ficam suspensos em campos de texto, buscas e diálogos. Combinações com Ctrl, Cmd ou Alt continuam disponíveis para o navegador.

| Tecla | Ação |
| --- | --- |
| V | Selecionar e arrastar objetos |
| H | Mover câmera |
| W | Desenhar parede |
| D | Inserir porta em uma parede |
| J | Inserir janela em uma parede |
| S | Criar sala / área |
| R / Shift+R | Girar a peça selecionada em +15° / −15° |
| L | Ocultar / exibir legendas nesta tela |
| G | Ocultar / exibir grade |
| M | Alternar seleção múltipla |
| E / O | Revelar / ocultar área com névoa ativa |
| F | Centralizar cena |
| + / − | Ajustar zoom |
| Esc | Cancelar gesto, limpar seleção e voltar a selecionar |

Construção (W, D, J, S) está disponível no modo **Montar cena**. A rotação exige uma única peça selecionada e respeita seu bloqueio; paredes levam portas e janelas vinculadas consigo. Durante um arraste, apenas Esc interrompe o gesto, descartando sua prévia.

O controle **Legendas** é uma preferência temporária desta tela: esconde nomes de objetos, salas e personagens, preservando anotações de texto, estados de porta e marcadores de condição. Ele não altera a visibilidade dos objetos para os jogadores.

As ferramentas mostram suas teclas e oferecem uma lista em **Atalhos do teclado**. Salas, paredes, portas e janelas usam acabamento de piso, alvenaria, madeira e vidro, incluindo as miniaturas da barra e da biblioteca. O acabamento se aplica também às cenas existentes.
